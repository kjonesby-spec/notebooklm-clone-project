# 1–2 Minute Demo Script

1. Show the live cloud URL and create a notebook named `RAG Study`.
2. Upload `sample_sources/intro_to_rag.txt` and one PDF or webpage.
3. Ask: “How does RAG work?” Point out inline citations and retrieved source references.
4. Switch to another notebook and show that its sources/chat are separate; switch back.
5. Generate the report and quiz, preview them, and click the download files.
6. Open Evaluation and compare similarity with MMR.
7. Briefly show the GitHub repository and the successful Actions run.

Record the browser, keep the cursor deliberate, and verify that no API key appears on screen.
