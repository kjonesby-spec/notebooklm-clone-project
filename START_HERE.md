# Start Here

1. Read `README.md` and the PDF guide in `docs/`.
2. Create `.env` from `.env.example` and add your Gemini API key.
3. Install requirements and run `python app.py`.
4. Test with `sample_sources/intro_to_rag.txt`.
5. Complete the real retrieval evaluation in `docs/evaluation_template.md`.
6. Push to your existing GitHub repository and deploy.
7. Record the demo using `docs/demo_script.md`.
8. Finish every item in `SUBMISSION_CHECKLIST.md`.

Before submitting, replace all `YOUR ...` and `ADD URL` placeholders in `README.md`.
